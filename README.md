# Country Explorer API

## Overview
Country Explorer is a web application built with Node.js and JavaScript that allows users to explore country information using an external REST API.

## Features
- Browse country information.
- Search for countries.
- Filter countries.
- View detailed information about individual countries.

## Technologies Used
- Node.js
- JavaScript
- HTML5
- CSS3
- REST API
- Git and GitHub

## How to Run the Project

1. Clone or download this repository.
2. Install the project dependencies:

   ```bash
   npm install
   ```

3. Create a `.env` file in the project root and add your own API key:

   ```text
   API_KEY=your_api_key_here
   ```

4. Start the application using the start command defined in `package.json`.
5. Open the local address shown by the server in your browser.

## Security
The API key is stored in a local `.env` file and should never be committed to GitHub.
